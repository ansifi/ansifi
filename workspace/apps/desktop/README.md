# Ansif Workspace — desktop (Electron)

Wraps the local hub at `http://127.0.0.1:4040/`.

```bash
./launch.sh
```

Dock **A** icon runs `./run.sh lan` (hub on the LAN for the phone) and publishes **http://ansif-workspace.local:4040/**. Closing the window runs `./run.sh stop`. Hub path: `/home/ansif/works/00_Ansif/workspace` (`ANSIF_WORKSPACE` to override). File → Copy phone URL.
